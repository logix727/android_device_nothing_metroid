## SIM2/eSIM mux

- r49 removes the one-way automatic eSIM boot heuristic and exposes an explicit
  `SIM 2 mode` chooser. QTI confirms mode `0` is physical SIM2 and mode `1` is
  eSIM; both requests return `errorCode=0`.
- eSIM -> physical mode plus reboot hides the eUICC, disconnects SIM2 secure
  element, and exposes slot 1 as physical. It reports absent because no physical
  card is currently inserted.
- physical -> eSIM mode plus reboot restores eUICC/EID routing and the same active
  US Mobile profile intact. Encrypted userdata, SELinux Enforcing and empty pstore
  persist.
- External gate: insert a real card in tray position 2, select Physical SIM 2,
  reboot, and prove subscription, data, SMS and calls. The mode is mutually
  exclusive with eSIM; three simultaneous subscriptions are impossible.
