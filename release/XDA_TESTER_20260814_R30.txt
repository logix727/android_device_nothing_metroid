FRESH INSTALL / RECOVERY SIDELOAD
1. Use only recovery/bootstrap images from this exact r30 snapshot.
2. In recovery, select Apply update -> Apply from ADB.
3. Run `adb sideload lineage-23.0-20260814-UNOFFICIAL-metroid.zip`.
4. Confirm recovery reports success. Host transfer percentage alone is not an
   install result.
5. Before first Android boot, reboot to the new-slot recovery and sideload
   MindTheGapps 16 ARM64 if Google apps are wanted. Its expected SHA-256 is
